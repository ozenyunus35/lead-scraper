        What happens on every run

        1. Crawl politelyChecks robots.txt, waits between requests, retries with back-off and sends a clear user agent.
        2. Follow the structureCategory pages, then pagination, then each business page, collecting every listing once.
        3. CleanPhone numbers in any format become E.164; addresses split into street, city, state and ZIP.
        4. De-duplicateThe same business listed twice is merged by phone number, keeping the most complete record and all categories.
        5. ExportCSV, a formatted Excel workbook and JSON, published here by a scheduled GitHub Actions job.

        The business directory is a demo site with invented businesses (phone numbers in the fictional 555-01xx range), built for this showcase. The books dataset comes from books.toscrape.com, a public sandbox made for scraping practice.
